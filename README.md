# Fluxo de Estratificação Cerâmica

Projeto autoral de estudo, desenvolvido como entrega do desafio **Design Patterns com Java: dos clássicos (GoF) ao Spring Framework**, da DIO.

O objetivo é consolidar o padrão de projeto **Strategy** em Java puro por meio de um planejador didático de prazos para ordens de estratificação cerâmica.

> **Aviso:** todos os prazos e exemplos deste projeto são fictícios. O projeto não utiliza dados de pacientes nem informações clínicas.

## Escopo da primeira versão

- Java puro, com compilação direcionada ao Java 21;
- padrão Strategy;
- três complexidades: simples, intermediária e complexa;
- prazos fictícios de 3, 5 e 8 dias corridos;
- demonstração pelo terminal;
- sem Spring, API REST ou banco de dados.
